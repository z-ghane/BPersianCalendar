# نصب

## .nupkg

### از طریق NuGet

  از طریق NuGet اقدام کنید:

```sh
dotnet add package BPersianCalendar
```


### از طریق Microsoft Visual Studio > Manage NuGet Packages
  
  1. **Manage NuGet Packages** را باز کنید
  
  2. `BPersianCalendar` را جستجو کنید
  
  3. **Install** را انتخاب کنید.




## .dll

به بخش references پروژه‌تان اضاف کنید.

سپس در toolbox گزینه add tab را انتخاب کرده و فایل .dll را به آن معرفی کنید.
